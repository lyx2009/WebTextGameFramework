                  故事对象结构（JSON / JS）：
{
  id: "story-id",              // 唯一标识，用于存档隔离
  title: "故事标题",
  subtitle: "副标题",
  description: "简介",
  theme: "test-theme",         // 主题 id：test-theme/ocean-theme/night-theme/dusk-theme/forest-theme
  chapters: [ ... ]            // 章节数组
}

章节对象：
{
  id: "ch1",
  title: "第一章标题",
  subtitle: "副标题",
  startScene: "s1",            // 起始场景 id
  scenes: { "s1": {...}, ... } // 场景表（以 id 为键）
}

场景对象：
{
  speaker: "旁白",
  text: "正文，可用 \n 换行",
  texture: "dawn",             // 贴图：dawn/forest/night/cave/lake/ocean/abyss
  next: "s2",                  // 无选项时的跳转，可用 "__chapterEnd__" 表示章节结束
  choices: [ ... ]             // 选项数组（有选项时优先显示选项）
}

选项对象：
{
  text: "选项文案",
  next: "s3",                  // 跳转场景 id 或 "__chapterEnd__"
  set: "hasItem",              // 可选：点击后写入的标记
  require: "hasItem"           // 可选：需要已持有该标记才显示
}

完整示例：
window.StoryRegistry.register({
  id: "my-story",
  title: "我的故事",
  subtitle: "示例",
  description: "一段示例",
  theme: "test-theme",
  chapters: [{
    id: "ch1",
    title: "第一章",
    subtitle: "",
    startScene: "s1",
    scenes: {
      "s1": {
        speaker: "旁白",
        text: "你醒来了。",
        texture: "dawn",
        choices: [
          { text: "继续前进", next: "s2" },
          { text: "结束", next: "__chapterEnd__" }
        ]
      },
      "s2": {
        speaker: "旁白",
        text: "故事仍在继续。",
        texture: "forest",
        next: "__chapterEnd__"
      }
    }
  }]
});

说明：
1. "__chapterEnd__" 表示本章结束并进入下一章；最后一章结束即通关。
2. 方式 A：在编辑工具中编辑后「导出 JS」，把文件放到 src/js/data/stories/ 下，
   并在 index.html 底部追加一行：
   <script src="src/js/data/stories/你的文件.js"></script>
3. 方式 B：在编辑工具中「导出 JSON」，再到 index.html 故事页「导入故事」直接游玩。
4. 编辑器额外维护可选的 chapter.sceneOrder 数组用于场景排序，游戏引擎会忽略它。
5. 人物：故事可携带 characters 数组，字段含 id/name/role/personality/description/affinity/target。
6. 好感度：选项可用 affinity（如 { lin: 1 }）增减好感，用 requireAffinity（如 { lin: 2 }）做显示门槛。
7. 对话：统一写入 dialog.json，按「故事 id -> 对话 id」组织，行内 speaker 用角色 id 区分角色；
   场景或选项可用 dialogue 字段引用对话 id。编辑器中可用「导入对话」把现成的 dialog.json
   载入继续编辑（也支持只含当前故事对话表的简化文件）。
8. 部署提示：index.html / edit.html / admin.html 中的 CSS、JS 链接均带 ?v= 版本号，
   修改已有静态资源后请递增该版本号，否则浏览器或 CDN 可能继续使用旧缓存，
   出现「页面结构已更新、样式仍是旧的」问题。

                  流程图使用说明

                  • 方块 ＝ 一个场景：方块里显示场景编号、说话人、正文前几行，以及它通向哪些场景。带「对话 xxx」标签，表示这个场景会播放一段对话。
                  • 箭头 ＝ 剧情走向：从一个场景指向下一个场景。一个场景有多条箭头时，就是分支（选项）。
                  • 点一下方块 ＝ 开始编辑：右侧面板可以直接改说话人、正文；选「直接跳转」（没有选项时走这里）；关联或查看对话；增删改每个选项；也可以上传 / 清除这张场景的背景图。
                  • 拖方块底部的「＋」＝ 连线：拖到另一个方块上松手，会自动给这个场景加一个选项并指向对方；松手后在右侧填好选项文案即可。
                  • 拖动方块本身 ＝ 改位置：只影响这张图的排版，不影响剧情。
                  • 拖动空白处 ＝ 平移画布；滚轮 / 放大 / 缩小 ＝ 缩放；重置 回到初始视角；适配 把整张图缩放到正好看得全。
                  • 新增场景＝在当前章节加一个新场景；删除该场景＝删除选中的场景（其它指向它的跳转会被清空）。
                  • 使用说明＝就是本页；表单＝切回原来的表单编辑器，内容和流程图完全一致，只是换一种编辑方式。
                  • 顶部「章节」下拉＝在章节之间切换；手机上画布会自动改成「从上到下」的单列排版，更方便手指操作。
                  • 小提示：节点位置只保存在本机浏览器，不会写进故事文件，也不会影响游戏里的剧情。
