# 素材分类说明

本目录按素材类型分子文件夹存放，便于后期扩展维护。

```
img/
├── icons/       # 图标类素材（logo、按钮图标等）
└── textures/    # 纹理/贴图类素材（噪点、纸张、背景纹理等）
```

当前已放置的素材：

- `icons/logo.svg`：游戏图标（页头与标题使用）。
- `textures/grain.svg`：颗粒噪点纹理，用作全屏氛围遮罩（见 `base.css` 的 `.grain-overlay`）。

## 放置建议

- 新增图标放入 `icons/`，并优先使用 SVG 以保证清晰度。
- 新增纹理/背景图放入 `textures/`。
- 若后续出现角色立绘、场景图等，可再新建对应子文件夹（例如 `characters/`、`scenes/`）。

场景贴图的主体由 `src/js/render.js` 在画布上程序化绘制，本目录主要存放可复用的静态纹理素材。
