# saves 目录说明

本目录用于存放导出的存档文件（JSON），便于按用户名整理、备份与迁移。

## 使用方式

1. 在游戏内选择一个故事，点击「存档」→ 输入用户名 → 选择槽位保存。
2. 点击「导出存档」，浏览器会下载一个以用户名命名的文件，例如 `玩家.json`。
3. 将下载的文件放入本 `saves/` 目录，即可长期保存。

读取时，在对应故事内点击「读档」→「导入存档」，选择 `saves/` 目录中对应的 JSON 文件即可恢复该故事下该用户的全部槽位。

## 存档文件命名

- 文件名与用户名一致，例如用户 `alice` 对应 `alice.json`。
- 一个文件内含该用户在某个故事下的全部 10 个档位（`slots` 数组）。
- 文件内包含 `storyId` 字段，导入时会自动写入对应故事，避免跨故事串档。

## 存档隔离

- 存档按「故事 + 用户名」双层隔离：同一用户名在不同故事下的存档互不影响。
- 导出的 JSON 文件携带 `storyId`，可据此判断该文件属于哪个故事。

## 说明

由于纯静态页面无法直接写服务器磁盘，游戏内的存档本体保存在浏览器 localStorage 中（按「故事 + 用户名 + 10 档位」组织），导出的 JSON 文件是它们的可迁移副本。两者内容一致，可通过「导入存档」互相恢复。
